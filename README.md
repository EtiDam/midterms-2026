# Midterms 2026 — carte des résultats

Module iframe (Blick) : carte en hexagones des États américains, résultats en direct du Sénat, de la Chambre et des gouverneurs.
Données : [civicAPI](https://civicapi.org) (attribution requise).

Paramètres : `lang=fr|de`, `race=senate|house|governor`, `layout=home`, `demo=1` (données fictives).
